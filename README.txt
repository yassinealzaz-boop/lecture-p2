Récitation (Android) : ouvrir ce dossier dans Android Studio, attendre la synchronisation Gradle,
puis Build > Build APK(s). L'APK est dans app/build/outputs/apk/debug/.
Le micro utilise la reconnaissance vocale d'Android en arabe (ar-SA), connexion internet conseillée.

Sans Android Studio : créer un dépôt GitHub, y envoyer le CONTENU de ce dossier (le dossier .github doit être à la racine),
puis onglet Actions > Build APK > à la fin, télécharger « recitation-apk » dans Artifacts.
